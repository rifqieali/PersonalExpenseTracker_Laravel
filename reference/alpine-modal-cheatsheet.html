Modal Blade + Alpine: pola minimal

Aturan issue #12: Blade render list, Alpine hanya show/hide. Tanpa SPA, tanpa x-for.

Kerangka

<div x-data="{ open:false, selected:null }" @keydown.escape.window="open = false">
  <table>
    @forelse($transactions as $t)
      <tr>
        <td>{{ $t->description }}</td>
        <td>
          @php
            $row = ['description' => $t->description, 'category_name' => $t->category->name ?? '-', 'type' => $t->type, 'amount' => $t->amount];
          @endphp
          <button
            @click="selected = JSON.parse($event.currentTarget.dataset.row); open = true"
            data-row='@json($row)'>Detail</button>
        </td>
      </tr>
    @endforelse
  </table>
  <div x-show="open" x-cloak x-transition class="fixed inset-0 z-50">
    <div @click="open = false" class="absolute inset-0 bg-black/50"></div>
    <div @click.stop class="relative bg-white p-4">
      <p x-text="selected?.description ?? '-'"></p>
      <p x-text="selected?.category_name ?? '-'"></p>
      <button @click="open = false">Tutup</button>
    </div>
  </div>
</div>
<style>[x-cloak]{display:none!important}</style>

Glosa singkat

IstilahArtinya
x-dataMemori komponen; menempel di satu elemen DOM.
x-showTampilkan/sembunyikan tanpa hapus dari DOM.
@click / x-onDengar event; isinya ekspresi JS.
dataset / data-*Jembatan string dari Blade ke JS.
@jsonCetak array PHP jadi JSON aman untuk atribut.
x-cloakSembunyikan sampai Alpine siap (butuh CSS).

Jangan

  • Jangan taruh <div> langsung di dalam <table>.
  • Jangan lupa open = true di tombol Detail.
  • Jangan baca $t dari Alpine — selalu via data-*/@json.
  • Jangan pakai x-for di issue ini.
