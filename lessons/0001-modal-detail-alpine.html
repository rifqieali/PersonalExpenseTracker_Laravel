Modal Detail: 4 konsep yang salah di kodenya

Satu kemenangan: kamu bisa menunjuk baris yang salah dan tahu perbaikannya tanpa menebak.

Konteks: di branch feat/alpineDetail, file resources/views/transactions/index.blade.php:43–52 ada satu blok x-data di dalam <table>, satu tombol Detail di luar loop, dan modal yang tidak pernah terbuka. Ini bedah konsepnya.

1. Scope: state tinggal di elemen x-data

x-data="{ open:false, selected:null }" artinya: "elemen ini punya memori open dan selected, hanya anak-anaknya yang boleh pakai." Kodenya menaruh x-data mengelilingi satu tombol di atas tabel — di luar @forelse. Jadi tombol itu tidak kenal baris mana yang diklik.

Salah. Satu x-data di atas tabel + satu tombol tanpa data baris.
Benar. Satu x-data membungkus seluruh tabel + modal, dan tombol Detail ada di dalam loop per baris, masing-masing membawa datanya sendiri. (Alpine Start Here)

2. Sintaks event: harus assignment

@click="selected {$event.currentTarget.dataset}"   ← bukan JS valid

Kurawal tanpa = tidak mengisi apa-apa, dan open tidak pernah jadi true — maka x-show="open" selamanya sembunyi. Ditambah tombolmu tidak punya atribut data-*, jadi dataset-nya kosong.

Benar. @click="selected = { description: '...' }; open = true" — isi dulu, baru buka.

3. Batas Blade vs Alpine: server vs browser

Laravel/Blade render di server (jadi HTML), Alpine hidup di browser (setelah HTML sampai). Alpine tidak bisa membaca variabel $t langsung — harus dititipkan lewat HTML: atribut data-* atau @json. Itulah jawaban interview untuk "kenapa data tetap dari Laravel": Laravel menyiapkan data, Alpine hanya show/hide. (Blade Docs)

<button
  @click="selected = JSON.parse($event.currentTarget.dataset.row); open = true"
  data-row='@json(["description" => $t->description, "amount" => $t->amount])'>
  Detail
</button>

4. Struktur HTML: <div> tidak boleh jadi anak langsung <table>

Browser otomatis mengeluarkan <div> dari dalam <table> (HTML invalid), jadi layout pecah. Modal juga belum punya backdrop, tombol close, atau Escape.

Benar. Modal di luar/bawah tabel sebagai overlay fixed inset-0: backdrop pakai @click.self="open = false", jendela dengar @keydown.escape.window="open = false". (pola resmi Escape + click.outside)
<div x-data="{ open:false, selected:null }" @keydown.escape.window="open = false">
  <table>... @forelse ... tombol Detail per baris ... @endforelse </table>
  <div x-show="open" x-cloak class="fixed inset-0">
    <div @click="open = false" class="absolute inset-0 bg-black/50"></div>
    <div @click.stop class="relative bg-white p-4">
      <p x-text="selected?.description"></p>
      <button @click="open = false">Tutup</button>
    </div>
  </div>
</div>

Catatan: x-cloak butuh CSS [x-cloak]{display:none} supaya modal tidak kedip sebelum Alpine siap. Dan branch-mu feat/alpineDetail ≠ issue/12-detail-modal yang diminta issue — ganti nama saat siap.
